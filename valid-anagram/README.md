# Valid Anagram

Dado duas strings `s` e `t`, retornar `true` se `t` é um anagrama de `s`, e `false` caso contrário.

Um **anagrama** é uma palavra ou frase formada pela reorganização das letras de uma outra palavra ou frase, utilizando normalmente todas as letras originais exatamente uma vez.

Link: https://neetcode.io/problems/valid-anagram
