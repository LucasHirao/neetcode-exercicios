# NeetCode Exercícios

Repositório com as resoluções dos exercícios da [NeetCode](https://neetcode.io/), escritas em Java.

## Organização

Cada exercício fica em sua própria pasta, nomeada em kebab-case a partir do título do problema. Dentro dela:

- `Solution.java` — a resolução do exercício.
- `README.md` — enunciado resumido, abordagem utilizada e complexidade de tempo/espaço.
